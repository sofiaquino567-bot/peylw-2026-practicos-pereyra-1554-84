2. ¿Por qué es fundamental utilizar etiquetas semánticas como <main> o <nav> en lugar de usar etiquetas genéricas <div> para estructurar todo el sitio?

Es fundamental utilizar etiquetas semánticas como <main> o <nav> en lugar de utilizar etiquetas genéricas <div> para estructurar todo el sitio, debido a que las etiquetas semánticas permiten delimitar claramente las zonas funcionales de una interfaz web. Por ejemplo, <main> indica el contenido principal del documento, mientras que <nav> define un bloque que contiene enlaces de navegación.

A diferencia de las etiquetas genéricas, las etiquetas semánticas brindan diferentes beneficios, como un código más claro, legible y estructurado para los equipos de desarrollo. Además, ayudan a los motores de búsqueda a comprender mejor la estructura y el contenido de la página. También mejoran la accesibilidad, ya que los lectores de pantalla y otras tecnologías asistivas pueden identificar y navegar más fácilmente entre las diferentes secciones del documento.
